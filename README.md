# Korean Study

Web tự học tiếng Hàn: Vite + React + TypeScript + Tailwind. Không backend, tiến độ lưu trong localStorage.

```
npm install
npm run dev      # chạy thử
npm run build    # build ra dist/, deploy thư mục này lên Vercel/Netlify/GitHub Pages
```

Thêm nội dung: sửa file JSON trong `src/data/` (`vocabulary.json`, `grammar.json`, `hangul.json`).
